# Security Policy & Vulnerability Reporting

The Telepresence GUI team takes the security and integrity of local workstation environments and Kubernetes cluster proxies seriously.

---

## 🛡️ Supported Versions

We provide security updates and patches for the following versions:

| Version Branch | Supported |
| :--- | :--- |
| `v1.x` (Latest Release) | ✅ Yes |
| `< v1.0` (Pre-releases) | ❌ No |

---

## 🔒 Reporting a Vulnerability

If you discover a security vulnerability or privilege escalation issue in Telepresence GUI, please **do not report it via public GitHub issues**.

Instead, please report it privately:

1. **Email**: Send detailed vulnerability information to [mahdimomeni012@gmail.com](mailto:mahdimomeni012@gmail.com).
2. **GitHub Security Advisory**: Alternatively, create a confidential [Security Advisory](https://github.com/mahdimomeni/telepresence-gui/security/advisories/new) on the repository.

### What to Include in Your Report:
- A clear description of the vulnerability and its potential impact.
- Step-by-step reproduction instructions or a proof-of-concept (PoC).
- Your operating system version, Telepresence CLI version, and Telepresence GUI version.

---

## ⏳ Response Timeline

- **Initial Response**: Within 48 hours.
- **Triage & Status Update**: Within 5 business days.
- **Patch Release & Public Disclosure**: Coordinated release following remediation.
