# Keyboard Shortcuts & Context Menus

Telepresence GUI provides native context menus and desktop keyboard shortcuts to accelerate navigation and data entry.

---

## ⌨️ Global Keyboard Shortcuts

| Shortcut (Win / Linux) | Shortcut (macOS) | Action |
| :--- | :--- | :--- |
| `Ctrl + F` | `Cmd + F` | Focus the workload search bar in Workload Browser. |
| `Ctrl + R` | `Cmd + R` | Force a manual reload of cluster workloads. |
| `Escape` | `Escape` | Close the active modal dialog (e.g., Intercept Dialog, Log Drawer). |
| `Enter` | `Enter` | Submit active form or start intercept in modal dialog. |
| `Ctrl + Q` | `Cmd + Q` | Cleanly terminate active daemons and quit the application. |

---

## 🖱️ Native Text Context Menus

Telepresence GUI features custom context menu integration across all text input fields, forms, and code views:

- **Right-Click inside any Input / Textarea**:
  - `Cut` (`Ctrl + X` / `Cmd + X`)
  - `Copy` (`Ctrl + C` / `Cmd + C`)
  - `Paste` (`Ctrl + V` / `Cmd + V`)
  - `Select All` (`Ctrl + A` / `Cmd + A`)
- **Right-Click on System Tray Icon**:
  - Toggles connection state, restores main dashboard window, or checks for updates.
