# Installation Overview

Telepresence GUI provides official, pre-compiled binaries and native installation packages for Windows, macOS, and Linux. All release assets are signed and hosted on the [**GitHub Releases Page**](https://github.com/mahdimomeni/telepresence-gui/releases/latest).

---
